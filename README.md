# LLM From Scratch

A hands-on journey to understand how neural networks, Transformers, and Large Language Models work by implementing and training models from scratch.

## Goal

The goal of this project is to understand the concepts behind modern language models rather than simply using pre-built APIs.

- [ ] Neural Networks

- [ ] Self-Attention
